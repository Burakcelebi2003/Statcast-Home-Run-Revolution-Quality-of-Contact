# Statcast-Home-Run-Revolution-Quality-of-Contact
Statcast-era analysis of batted-ball quality, xwOBA and home run production using regression, XGBoost, SHAP and clustering.
# MLB Statcast Dış Balistik ve Süreç Metrikleri Analizi 
2020 hariç 2015–2025 MLB Statcast verileri (477 oyuncu, 1.378 satır) üzerinde dış balistik ve süreç metriklerini incelemektedir. Exit Velocity, Launch Angle Sweet Spot% ve Pull% değişkenlerinin xwOBA ve Home Run üzerindeki etkileri korelasyon, K-Means kümeleme, doğrusal trend ve XGBoost-SHAP yöntemleriyle analiz edilmiştir. Bulgular, Exit Velocity'nin modeldeki en baskın değişken olduğunu ve yaklaşık 88–89 mph eşiğinden sonra xwOBA ve Home Run katkısının doğrusal olmayarak ivmelendiğini göstermektedir.
